# requirements-lock.txt —— 后端依赖的可复现锁定版本（供 CI 使用）

# 生成方式（务必在“干净的 Python 3.11”环境中生成，禁止用 Windows + Python 3.14
# 的 pip freeze 直接覆盖 Linux CI）：
#   python3.11 -m venv .venv311
#   .venv311/Scripts/python -m pip install --upgrade pip
#   .venv311/Scripts/python -m pip install -r requirements.txt
#   .venv311/Scripts/python -m pytest -q                 # 必须全绿
#   .venv311/Scripts/python benchmarks/run_benchmark.py  # 离线回归必须全过
#   .venv311/Scripts/python -m pip freeze > requirements-lock.txt
#
# 本锁在 Python 3.11.9 干净虚拟环境、pytest 全部通过、离线工程回归 20/20 通过后生成。
# 日常开发仍使用 requirements.txt（宽松约束，便于升级）；GitHub Actions 安装本锁文件，
# 保证“今天”和“以后”安装到的依赖版本一致、CI 可复现。
# 说明：该 freeze 在 Windows Python 3.11 生成，未包含仅 Unix 的 uvloop（uvicorn 会
# 自动回退到 asyncio 事件循环，不影响测试与运行）；其余包均提供 manylinux cp311 wheel。
